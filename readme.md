# DocRadar - 本地文档搜索系统

## 项目介绍

DocRadar是一个本地文档管理和搜索系统，旨在解决需要在大量产品文档中查找特定内容的问题。系统允许用户上传和存储文档，并通过模糊搜索快速找到相关内容，显著提高文档检索效率。系统特别适合离线环境或需要保密文档管理的场景。

## 功能特性

### 核心功能

1. **文档上传与存储**
   - 支持多种文档格式（PDF, Word, TXT等）
   - 文档本地永久存储
   - 文档元数据管理
   - 批量上传支持，同时处理多个文件
   - 文档覆盖检测与确认机制
   - 拖放上传支持

2. **高级搜索功能**
   - 全文搜索与模糊匹配并行支持
   - 搜索历史记录管理，支持删除与清空
   - 搜索标签管理，快速在多个搜索结果间切换
   - 无结果时友好提示，确保界面一致性
   - 搜索结果缓存，提高重复搜索性能

3. **结果展示与导航**
   - 匹配文本高亮显示，直观呈现匹配位置
   - 搜索导航器，在长文档中快速跳转匹配项
   - 多文档结果列表，按相关性排序
   - 文档预览与详细查看功能
   - 搜索结果片段显示，帮助快速判断相关性

4. **文档管理**
   - 文档列表浏览与搜索
   - 文档元数据显示（类型、大小、创建时间）
   - 支持文档删除与覆盖操作
   - 分页浏览与每页显示数量调整
   - 批量文档操作支持

### 特色功能

1. **富文本文档支持**
   - DOCX文档格式保留，包括标题、段落、表格等
   - 文档图片自动提取与显示
   - PDF文档内容精确解析
   - 文本文档编码自动识别
   - HTML内容保存，确保格式一致性

2. **用户体验优化**
   - 拖放上传支持
   - 上传进度实时显示
   - 批量操作友好界面
   - 响应式设计，适配不同设备
   - 自动消失的提示信息，提高用户体验

## 技术架构

### 后端

- **Python Flask**: 提供Web服务和路由管理
- **SQLite**: 存储文档元数据和全文搜索索引
- **Flask-Session**: 用户会话管理，保存搜索历史
- **文档解析引擎**:
  - PyPDF2/pdfplumber: PDF文件解析
  - python-docx: Word文档解析，包括图片提取
  - mammoth: 将DOCX转换为HTML，保留格式
  - 文本文件多编码支持
- **数据存储与检索**:
  - 文件系统存储原始文档
  - SQLite FTS5存储与索引文本内容
  - 混合匹配算法，结合FTS5和LIKE搜索

### 前端

- **HTML/CSS/JavaScript**: 基础UI构建
- **Bootstrap 5**: 响应式设计框架
- **Font Awesome/Bootstrap Icons**: 图标库
- **jQuery**: DOM操作和AJAX请求
- **自定义组件**:
  - 搜索导航器: 文档内快速定位和导航匹配项
  - 文件上传管理器: 批量文件处理与进度监控
  - 搜索标签系统: 在多个搜索结果间切换

## 数据库结构

DocRadar使用SQLite数据库来存储文档信息和全文搜索索引。以下是主要表的简要说明：

### 1. documents表

存储上传文档的元数据信息。

| 字段名 | 类型 | 说明 |
|-------|------|------|
| id | INTEGER | 主键，自动递增 |
| filename | TEXT | 原始文件名 |
| filepath | TEXT | 文件在服务器上的存储路径 |
| title | TEXT | 文档标题，通常从文档内容中提取 |
| file_type | TEXT | 文件MIME类型 |
| file_size | INTEGER | 文件大小(字节) |
| metadata | TEXT | 文档元数据(JSON格式) |
| created_at | TIMESTAMP | 上传时间，默认为当前时间 |
| original_filename | TEXT | 上传时的原始文件名 |

### 2. document_content表

使用FTS5(全文搜索)扩展创建的虚拟表，用于存储文档内容并支持全文搜索。

| 字段名 | 类型 | 说明 |
|-------|------|------|
| doc_id | INTEGER | 文档ID，关联documents表的id字段 |
| content | TEXT | 文档内容，用于全文搜索 |

### 3. document_html_content表

存储文档的HTML格式内容，用于更好地保留文档原始格式。

| 字段名 | 类型 | 说明 |
|-------|------|------|
| doc_id | INTEGER | 主键，文档ID，关联documents表的id字段 |
| html_content | TEXT | 文档的HTML格式内容，包含格式和图片链接 |

更详细的数据库说明见[database.md](database.md)文件。

## 实现细节

### 1. 文档上传与存储

- 用户通过拖放或文件选择器上传单个或多个文档
- 系统检测文件是否已存在，提供覆盖选项
- 异步上传处理，实时显示进度
- 文档解析器提取文本内容和元数据
- 文档存储在文件系统，元数据和内容索引存储在数据库
- DOCX文档中的图片自动提取并存储到静态目录

### 2. 搜索功能

- **两级搜索机制**：
  - 主要使用SQLite FTS5全文索引搜索
  - 备用使用内容模糊匹配（当FTS5失败或无结果时）
- **搜索历史管理**：
  - 基于用户会话(Session)存储搜索历史
  - 支持单条删除和批量清空
  - 标签式界面，快速切换不同搜索
- **结果高亮处理**：
  - 使用正则表达式匹配和替换实现高亮
  - 上下文截取，显示匹配项周围的文本

### 3. 搜索结果展示

- **结果列表**：
  - 按相关性排序的匹配文档
  - 每个结果显示文档标题、类型、大小和创建时间
  - 包含匹配内容的上下文预览
  - 高亮显示匹配的关键词
- **文档查看**：
  - 支持原格式查看（保留格式和图片）
  - 高亮所有匹配内容
  - 搜索导航工具条，快速跳转到不同匹配处
  - 提供原文档下载选项

### 4. 文档管理

- 分页浏览已上传文档
- 文档列表内搜索过滤
- 每页显示数量可调整
- 文档删除与管理功能
- 批量删除支持，提高管理效率

## 安装与运行

### 前提条件

- Python 3.8+
- pip (Python包管理器)
- SQLite 3.31.0+（支持FTS5扩展）
- 对于Windows用户，需要额外安装python-magic-bin

### 安装步骤

1. 克隆代码库
   ```
   git clone git@github.com:libai6666/DocRadar.git
   cd DocRadar
   ```

2. 创建虚拟环境(可选但推荐)
   ```
   python -m venv venv
   # Windows
   venv\Scripts\activate
   # Linux/Mac
   source venv/bin/activate
   ```

3. 安装依赖
   ```
   pip install -r requirements.txt
   
   # Windows系统还需要运行
   # pip install python-magic-bin==0.4.14
   ```

4. 初始化数据库
   ```
   python init_db.py
   ```

5. 运行应用
   ```
   python app.py
   ```

6. 在浏览器中访问 `http://localhost:5000`

## 使用指南

### 上传文档

1. 点击主页上的「选择文件」按钮或直接拖放文件到上传区域
2. 单次可以选择多个文件（按住Ctrl键多选）
3. 系统会自动处理并索引文档内容
4. 上传进度实时显示

### 搜索文档

1. 在主页或结果页面的搜索框中输入关键词
2. 执行完整搜索后，系统会保存搜索历史和结果
3. 使用标签页在不同的搜索结果之间切换
4. 可以单独删除某个搜索历史或清空所有历史
5. 在文档查看页面使用搜索导航器（页面右上角）在匹配项之间跳转

### 管理文档

1. 在主页文档列表中搜索或浏览文档
2. 使用每个文档右侧的按钮查看、下载或删除文档
3. 勾选多个文档进行批量删除操作
4. 调整分页控件选择每页显示数量

### 数据库管理

1. 访问管理页面 `http://localhost:5000/admin/db?key=YOUR_ADMIN_KEY`
   - ADMIN_KEY在admin_config.json文件中配置
2. 查看表结构、表数据、执行SQL查询
3. 导出数据或执行表格操作
