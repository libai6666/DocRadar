# DocRadar - 本地文档搜索系统

## 项目介绍

DocRadar是一个本地文档管理和搜索系统，旨在解决需要在大量产品文档中查找特定内容的问题。系统允许用户上传和存储文档，并通过多种搜索策略快速找到相关内容，显著提高文档检索效率。系统特别适合离线环境或需要保密文档管理的场景，支持多环境部署（测试/生产），确保数据隔离与安全。

## 功能特性

### 文档管理功能

1. **高级文档上传系统**
   - **多格式支持**：无缝处理PDF、Word(DOCX/DOC)和TXT文档
   - **智能批量处理**：单次上传多个文件，自动分批处理减轻服务器压力
   - **拖放支持**：现代化的拖放界面与传统文件选择器并行支持
   - **重试机制**：上传失败自动重试（最多3次），提高可靠性
   - **错误恢复**：记录并显示失败文件，提供重新上传选项
   - **实时进度展示**：
     - 顶部固定进度条，无需滚动即可查看上传状态
     - 详细显示当前处理文件和总体进度百分比
     - 文件队列预览与选择性上传
   - **文件覆盖处理**：
     - 精确的文件重复检测系统
     - 单文件覆盖确认模态框
     - 批量覆盖选择界面，支持选择覆盖特定文件
     - 可取消上传操作

2. **文档存储与组织**
   - **分层存储架构**：
     - 环境隔离：测试/生产环境数据完全分离
     - 多目录结构：uploads存储原始文件，document_images存储提取的图片
     - 年月目录自动组织：基于时间自动创建层级目录结构(YYYYMM)
   - **文件命名策略**：
     - 安全文件名处理（防注入、路径遍历）
     - 时间戳文件名格式，确保唯一性
     - 保留原始文件名用于显示与下载
   - **元数据管理**：
     - 自动提取文档标题、作者等元信息
     - 存储文件大小、类型、创建时间等关键信息
     - JSON格式灵活存储额外元数据

3. **文档列表与管理界面**
   - **分页浏览**：支持自定义每页显示数量(10/20/50)
   - **排序过滤**：按上传时间、大小、类型等多维度排序
   - **搜索过滤**：在已上传文档中快速定位
   - **批量操作**：
     - 全选/反选/单选机制
     - 批量删除功能，提高管理效率
     - 操作确认机制，防止误操作
   - **文件操作菜单**：
     - 查看文档内容与预览
     - 下载原始文件
     - 删除文件（带确认）

### 文档解析与内容处理

1. **智能文档解析引擎**
   - **PDF文档处理**：
     - 使用PyPDF2与pdfplumber双重引擎提取文本
     - 智能页面识别与文本提取
     - 处理受保护PDF自动降级策略
   - **Word文档处理**：
     - 完整解析DOCX文档结构（段落、表格、列表）
     - 自动提取文档属性（标题、作者、修改日期）
     - 文档结构保留与转换
   - **图片提取与处理**：
     - 自动从DOCX中提取嵌入图片
     - 保留图片原始宽高比
     - 年月目录自动组织图片存储
     - 生成唯一图片标识符防止覆盖
     - 图片URL自动构建与管理
   - **TXT文档处理**：
     - 多编码支持（UTF-8, GBK, GB2312等）
     - 自动编码检测与回退机制
     - 简单格式化显示

2. **文档到HTML转换系统**
   - **富文本保留技术**：
     - 使用mammoth库实现DOCX到HTML的高保真转换
     - 保留标题层级、段落格式、表格结构
     - 自定义样式映射确保显示一致性
   - **图片处理与嵌入**：
     - 图片内联处理，确保与文本位置一致
     - 响应式图片显示，适应不同屏幕尺寸
     - 图片库显示，支持查看所有提取的图片
   - **表格增强**：
     - 表格自动添加边框与样式
     - 水平滚动支持，处理宽表格
     - 表格响应式设计，适应移动设备

### 搜索与内容查找功能

1. **多层次搜索引擎**
   - **全文检索**：
     - 基于SQLite FTS5全文检索引擎
     - 支持部分词匹配与完整词匹配
     - 中英文搜索优化，忽略大小写
   - **备用模糊搜索**：
     - 当FTS5无结果时自动降级到LIKE搜索
     - 支持多词条搜索，提高召回率
     - 自动扩展搜索范围（标题、内容、文件名）
   - **搜索结果排序**：
     - 基于相关性评分排序
     - 优先显示标题匹配结果
     - 最近上传文档权重提升

2. **搜索历史管理**
   - **会话持久化**：
     - 基于Flask-Session保存搜索历史
     - 支持多标签页搜索结果并行查看
     - 搜索历史跨页面保持
   - **标签式界面**：
     - 直观的标签页设计，快速切换不同搜索
     - 每个标签显示查询词与时间
     - 单个搜索删除功能（带交互反馈）
     - 一键清空全部历史
   - **搜索状态保持**：
     - 页面刷新后保持当前搜索结果
     - 浏览器后退支持，返回上一个搜索

3. **搜索结果展示**
   - **智能预览生成**：
     - 提取匹配上下文，创建有意义预览
     - 自动定位最佳匹配段落
     - 截取适当长度，确保可读性
   - **高亮处理**：
     - 多级高亮系统（普通、当前、超级高亮）
     - 支持部分词匹配高亮
     - 防止HTML注入的安全处理
   - **结果元数据**：
     - 显示文档类型、大小、上传时间
     - 原始文件名显示
     - 匹配数量统计

4. **高级文档查看器**
   - **搜索导航系统**：
     - 固定在顶部的导航工具条
     - 当前匹配/总匹配数显示
     - 上下导航按钮与键盘快捷键(Enter/Shift+Enter)
     - 智能滚动定位，自动将当前匹配项居中显示
   - **格式保留显示**：
     - 保持原始文档格式（标题、段落、表格）
     - 图片内联显示，与原始位置一致
     - 响应式设计，适应不同设备屏幕
   - **交互增强**：
     - 点击任意匹配项立即导航
     - 键盘导航支持(F3/Shift+F3)
     - 自动跟踪滚动位置，更新当前匹配项

## 技术架构

### 后端技术栈

- **Web框架**：Flask作为轻量级Web服务器
- **数据存储**：
  - SQLite数据库 (支持FTS5全文检索)
  - 文件系统存储 (分层目录结构)
- **文档处理**：
  - PyPDF2/pdfplumber：PDF文件解析
  - python-docx：Word文档解析与图片提取
  - mammoth：DOCX到HTML高保真转换
- **会话管理**：Flask-Session
- **安全组件**：Flask-WTF (CSRF保护)
- **部署工具**：Gunicorn, Docker

### 前端技术栈

- **基础框架**：HTML5, CSS3, JavaScript (ES6+)
- **UI框架**：Bootstrap 5 (响应式设计)
- **图标库**：Bootstrap Icons
- **AJAX处理**：原生Fetch API
- **自定义组件**：
  - 搜索导航器 (search-navigator.js)
  - 文件上传管理器 (main.js)
  - 搜索标签系统 (动态创建与管理)

### 数据流架构

1. **文档上传流程**：
   - 文件选择/拖放 → 文件验证 → 存在性检查 → 保存到文件系统 → 文档解析 → 内容提取 → 数据库索引

2. **搜索流程**：
   - 查询输入 → 历史保存 → FTS5搜索 → (可选)降级搜索 → 结果排序 → 预览生成 → 高亮处理 → 结果呈现

3. **文档查看流程**：
   - 点击结果 → 获取原始内容 → 高亮处理 → 导航器初始化 → 定位到首个匹配项 → 交互导航

## 实现细节

### 1. 文档解析引擎

DocRadar采用多层次文档解析策略，根据文件类型使用不同的解析器：

- **PDF解析**：结合PyPDF2与pdfplumber的优势，优先使用pdfplumber提取格式化文本，失败时自动降级到PyPDF2
- **DOCX解析**：使用python-docx解析文档结构，mammoth转换为HTML，自定义处理嵌入图片
- **TXT解析**：智能编码检测，支持多种编码格式，自动处理编码问题

图片处理流程特别复杂：
1. 从DOCX提取二进制图片数据
2. 保存到按年月组织的物理目录
3. 生成唯一图片ID防止冲突
4. 创建专用URL路径用于访问
5. 保留图片尺寸信息用于显示
6. 在HTML内容中正确引用图片

### 2. 搜索系统

搜索引擎采用双重策略，确保查询结果的准确性与全面性：

- **主要策略**：使用SQLite FTS5(全文搜索)提供高效索引查询
- **备用策略**：当FTS5无结果时，使用SQL LIKE查询进行模糊匹配

搜索导航器(SearchNavigator)是一个前端JavaScript类，实现以下功能：
- 在文档中定位并高亮所有匹配项
- 提供导航控制(上一个/下一个)
- 显示当前位置(如"3/15")
- 自动滚动到当前匹配项
- 支持键盘导航与交互

### 3. 存储架构

系统使用混合存储架构：

- **SQLite数据库**：存储元数据和全文索引
  - documents表：文档元数据(文件名、路径、类型等)
  - document_content表：使用FTS5索引的文本内容
  - document_html_content表：格式化的HTML内容(展示用)

- **文件系统**：按逻辑组织的多层结构
  - data/[env]/uploads：原始文档存储
  - data/[env]/document_images/[YYYYMM]/[doc_id]：文档图片存储
  - logs/[env]：环境隔离的日志存储

## 安装与运行

### 前提条件

- Python 3.8+
- pip (Python包管理器)
- SQLite 3.31.0+（支持FTS5扩展）
- 对于Windows用户，需要额外安装python-magic-bin

### 安装步骤

1. 克隆代码库
   ```
   git clone git@github.com:libai6666/DocRadar.git
   cd DocRadar
   ```

2. 创建虚拟环境(可选但推荐)
   ```
   python -m venv venv
   # Windows
   venv\Scripts\activate
   # Linux/Mac
   source venv/bin/activate
   ```

3. 安装依赖
   ```
   pip install -r requirements.txt
   
   # Windows系统还需要运行
   # pip install python-magic-bin==0.4.14
   ```

4. 初始化数据库
   ```
   python init_db.py
   ```

5. 运行应用
   ```
   python app.py
   ```

6. 在浏览器中访问 `http://localhost:5000`

### Docker部署

1. 构建Docker镜像
   ```
   docker-compose build
   ```

2. 启动服务
   ```
   docker-compose up -d
   ```

3. 访问应用 `http://192.168.0.110:5000`（或配置的其他地址）
