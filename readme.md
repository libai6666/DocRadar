# DocRadar - 本地文档搜索系统

## 项目介绍

DocRadar是一个本地文档管理和搜索系统，旨在解决需要在大量产品文档中查找特定内容的问题。系统允许用户上传和存储文档，并通过模糊搜索快速找到相关内容，显著提高文档检索效率。

## 功能特性

### 核心功能

1. **文档上传与存储**
   - 支持多种文档格式（PDF, Word, TXT等）
   - 文档本地永久存储
   - 文档元数据管理
   - 批量上传支持，同时处理多个文件
   - 文档覆盖检测与确认机制

2. **高级搜索功能**
   - 模糊搜索匹配，支持部分关键词匹配
   - 实时搜索建议，快速反馈匹配结果
   - 搜索历史记录，便于追踪之前的查询
   - 支持全文检索，包括文档标题和内容
   - 无结果时友好提示，确保界面一致性

3. **结果展示与导航**
   - 匹配文本高亮显示，直观呈现匹配位置
   - 搜索导航器，在长文档中快速跳转匹配项
   - 多文档结果列表，按相关性排序
   - 文档预览与详细查看功能
   - 搜索结果片段显示，帮助快速判断相关性

4. **文档管理**
   - 文档列表浏览与搜索
   - 文档元数据显示（类型、大小、创建时间）
   - 支持文档删除与覆盖操作
   - 分页浏览与每页显示数量调整

### 特色功能

1. **富文本文档支持**
   - DOCX文档格式保留，包括标题、段落、表格等
   - 文档图片自动提取与显示
   - PDF文档内容精确解析
   - 文本文档编码自动识别

2. **用户体验优化**
   - 拖放上传支持
   - 上传进度实时显示
   - 批量操作友好界面
   - 响应式设计，适配不同设备

## 技术架构

### 后端

- **Python Flask**: 提供Web服务和路由管理
- **SQLite + FTS5**: 存储文档元数据和全文搜索索引
- **文档解析引擎**:
  - PyPDF2/pdfplumber: PDF文件解析
  - python-docx: Word文档解析，包括图片提取
  - 文本文件多编码支持
- **数据存储与检索**:
  - 文件系统存储原始文档
  - 数据库存储元数据和搜索索引
  - 二级搜索机制：优先使用FTS5，备用使用内容模糊匹配

### 前端

- **HTML/CSS/JavaScript**: 基础UI构建
- **Bootstrap 5**: 响应式设计框架
- **jQuery**: DOM操作和AJAX请求
- **自定义组件**:
  - 搜索导航器: 文档内快速定位和导航匹配项
  - 文件上传管理器: 批量文件处理与进度监控
  - 实时搜索建议: 快速反馈搜索结果

## 数据库结构

DocRadar使用SQLite数据库来存储文档信息和全文搜索索引。以下是各个表的详细说明：

### 1. documents表

存储上传文档的元数据信息。

| 字段名 | 类型 | 说明 |
|-------|------|------|
| id | INTEGER | 主键，自动递增 |
| filename | TEXT | 原始文件名 |
| filepath | TEXT | 文件在服务器上的存储路径 |
| title | TEXT | 文档标题，通常从文档内容中提取 |
| file_type | TEXT | 文件MIME类型 |
| file_size | INTEGER | 文件大小(字节) |
| metadata | TEXT | 文档元数据(JSON格式) |
| created_at | TIMESTAMP | 上传时间，默认为当前时间 |

### 2. document_content表

使用FTS5(全文搜索)扩展创建的虚拟表，用于存储文档内容并支持全文搜索。

| 字段名 | 类型 | 说明 |
|-------|------|------|
| doc_id | INTEGER | 文档ID，关联documents表的id字段 |
| content | TEXT | 文档内容，用于全文搜索 |
| title | TEXT | 文档标题，用于全文搜索 |

## 实现细节

### 1. 文档上传与存储

- 用户通过拖放或文件选择器上传单个或多个文档
- 系统检测文件是否已存在，提供覆盖选项
- 异步上传处理，实时显示进度
- 文档解析器提取文本内容和元数据
- 文档存储在文件系统，元数据和内容索引存储在数据库

### 2. 搜索功能

- **两级搜索机制**：
  - 主要使用SQLite FTS5全文索引搜索
  - 备用使用内容模糊匹配（当FTS5失败或无结果时）
- **模糊匹配算法**：
  - 支持关键词的部分匹配
  - 匹配分数计算，根据匹配度排序
  - 优先展示最相关结果
- **实时搜索建议**：
  - 用户输入时异步请求匹配结果
  - 立即展示前5个最相关结果
  - 提供完整结果页面链接

### 3. 搜索结果展示

- **结果列表**：
  - 按相关性排序的匹配文档
  - 每个结果显示文档标题、类型、大小和创建时间
  - 包含匹配内容的上下文预览
  - 高亮显示匹配的关键词
- **文档查看**：
  - 支持原格式查看（保留格式和图片）
  - 高亮所有匹配内容
  - 搜索导航工具条，快速跳转到不同匹配处
  - 提供原文档下载选项

### 4. 文档管理

- 分页浏览已上传文档
- 文档列表内搜索过滤
- 每页显示数量可调整
- 文档删除与管理功能

## 安装与运行

### 前提条件

- Python 3.8+
- pip (Python包管理器)
- SQLite 3.31.0+（支持FTS5扩展）

### 安装步骤

1. 克隆代码库
   ```
   git clone git@github.com:libai6666/DocRadar.git
   cd DocRadar
   ```

2. 创建虚拟环境(可选但推荐)
   ```
   python -m venv venv
   # Windows
   venv\Scripts\activate
   # Linux/Mac
   source venv/bin/activate
   ```

3. 安装依赖
   ```
   pip install -r requirements.txt
   ```

4. 运行应用
   ```
   python app.py
   ```

5. 在浏览器中访问 `http://localhost:5000`

## 使用指南

### 上传文档

1. 点击主页上的「选择文件」按钮或直接拖放文件到上传区域
2. 单次可以选择多个文件（按住Ctrl键多选）
3. 系统会自动处理并索引文档内容
4. 上传进度实时显示

### 搜索文档

1. 在主页或结果页面的搜索框中输入关键词
2. 实时显示匹配建议（输入2个以上字符时）
3. 点击搜索按钮或按Enter执行完整搜索
4. 在搜索结果页面点击文档查看详情
5. 在文档查看页面使用搜索导航器（页面右上角）在匹配项之间跳转

### 管理文档

1. 在主页文档列表中搜索或浏览文档
2. 使用每个文档右侧的按钮查看、下载或删除文档
3. 调整分页控件选择每页显示数量

### 数据库管理

1. 访问管理页面 `http://localhost:5000/admin/db?key=YOUR_ADMIN_KEY`
   - ADMIN_KEY在admin_config.json文件中配置
2. 查看表结构、表数据、执行SQL查询
3. 导出数据或执行表格操作
